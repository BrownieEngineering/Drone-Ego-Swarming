# Chapter 5 — Running the System

The previous chapters prepared and configured the Drone EGO Swarming
development environment.

This chapter describes the standard operating procedure used to launch
the complete simulation environment, verify communication between all
major components, and execute an autonomous mission.

Each procedure has been validated using the software versions documented
throughout this manual.

For best results, complete each section in the order presented.
